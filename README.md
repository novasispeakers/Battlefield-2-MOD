# NovasiBF2 — Battlefield 2 MOD

NovasiBF2 is an independent, community-oriented research and mod development project for **Battlefield 2**.

The long-term objective is to explore improvements to AI, squad coordination, gameplay systems, and technical capabilities while preserving the recognizable identity of the original game.

## Project status

**Workspace initialization.** The technical roadmap, contribution guidelines, engineering acceptance criteria, and project governance are being defined. No public development milestone or modified game build is announced at this stage.

## Collaboration

International collaboration is intended. Public project documentation, issues, pull requests, and code review discussions will be conducted in **English**.

Contribution procedures and code licensing have **not yet been finalized**. Please discuss substantial proposals before submitting implementations.

## Research scope

Current areas of interest include:

- Battlefield 2 AI behavior and squad cohesion;
- Refractor 2 engine research and binary analysis;
- Reproducible, reversible experiments;
- Preservation of previously validated gameplay behavior;
- Evaluating community research and existing open-source tools.

These are **research directions**, not claims that specific features have been implemented.

## Copyright and boundaries

Battlefield 2 and its original game assets belong to their respective rights holders. This repository is independent and is not affiliated with or endorsed by EA or DICE.

**Do not commit proprietary game executables, DLLs, copyrighted assets, credentials, or unauthorized distributions.** Any original project code and external contributions will be reviewed for provenance and licensing before publication.
